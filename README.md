# Job Application Tracker

A React-based job application tracker to manage and organize job applications.

## Features

* Add job applications
* Edit and delete applications
* Search and filter applications
* Track application status
* Store application data locally

## Technologies Used

* React
* JavaScript
* CSS
* Vite

## What I Practiced

* React components
* useState and state management
* Forms and controlled inputs
* Array methods
* Event handling
* Conditional rendering
* Local storage
* CRUD operations
